# openEMS PCB 안테나 — 빠른 근사와 제한된 검증을 위한 에이전트 규칙

개정: 2026-09-23 · 대상: 2.4–6 GHz PCB 안테나·수동 RF 구조 · Python API

목적은 **계산량이 작은 합리적 모델로 설계 판단에 필요한 결과를 얻고, 정해진 횟수 안에 신뢰 범위를 설명하는 것**이다. 기본 모델은 **속이 찬 PEC 비아 + 2D 동박 + 실제 주요 유전체/주변 구조**다. 모든 미세 형상을 재현하려고 하지 않는다.

이 문서의 수치 예산과 허용차는 빠른 설계 검토를 위한 운영 기본값이다. openEMS의 보장 사양이나 모든 안테나에 통용되는 정확도 기준이 아니다. 특정 프로젝트에 정해진 정확도·실행 예산이 있으면 그것을 우선한다. 이 문서는 수백 MHz 이하의 자성 코어 전류 프로브 교정에 그대로 적용하지 않는다.

## 1. 먼저 지킬 실행 원칙

1. **속이 찬 PEC 비아를 기본으로 사용한다.** 도금 링·빈 드릴 구멍·충전재·표피깊이를 직접 해상하는 모델은 기본 범위에서 제외한다. 이는 공식 FAQ의 권고와 맞는다. [1]
2. **동박은 2D PEC 시트로 시작한다.** 18/35 µm 두께 때문에 z 메시를 만들지 않는다. 효율/손실이 목적일 때는 같은 2D 형상에 ConductingSheet를 사용한다. [3]
3. **필요한 접속·갭·귀환 경로는 유지한다.** 메시를 편하게 만들기 위해 급전 갭을 닫거나, GND 층을 합치거나, 비아를 매번 옮기지 않는다.
4. **메시는 먼저 생성·검사하고, 본 계산은 뒤에 한다.** 거의 같은 실패 모델을 긴 시간 반복 실행하지 않는다.
5. **본 실행은 기본 1회 + 고정 형상 메시 비교 1회 + 원인이 특정된 보완 최대 1회**로 끝낸다. 통과하지 못하면 마지막 유효 결과와 한계를 보고한다. 무조건 세 번째 계산까지 수행하라는 뜻은 아니다.
6. 작은 Δt는 주로 **속도 문제**, 큰 인접 셀 비는 주로 **정확도/이산화 문제**, 필드의 지속 성장·NaN은 **발산 문제**다. 모두를 ‘메시 불안정’으로 부르지 않는다.

## 2. 기본 근사 — 별도 비교 없이 시작해도 되는 선택

‘기본 근사’는 빠른 모델을 시작하기 위한 선택이다. 실물 정확도가 이미 확인됐다는 뜻은 아니다.

| 대상 | 기본 모델 | 보존할 것 |
|---|---|---|
| 도금 비아 | `AddMetal` + **solid AddCylinder**, 반경=드릴/2 | 중심 좌표, 연결층, 중요한 패드/anti-pad와 stub |
| 트레이스·패드·GND | 두께 0 PEC sheet | 실제 평면 외곽, 급전, 단락/개방, 슬롯/갭 |
| 효율·도체손실이 목표인 동박 | 2D `AddConductingSheet` | σ와 실제 공칭 두께. via의 PEC 손실 생략도 기록 |
| 기판 | 실제 두께, 제조사 εr/tanδ 우선 | 신호와 가까운 리턴 사이 거리, 중요한 다층 구조 |
| 솔더마스크·실크 | 첫 모델에서 생략 | 가정 목록에 기록. 공진 이동을 일률적으로 1%라 쓰지 않음 |
| 작은 패키지·장식 형상 | 중요한 전계/전류 경로 밖이면 생략 | 안테나 가까운 금속, 급전부, 실장 패드, keep-out |
| 외부 폐금속 부품 | 외형을 단순한 PEC 형상으로 근사 가능 | 안테나와 거리·외곽·전기적 연결 |
| 하우징/금속 케이스 | 주요 유전체 벽/금속 벽과 내부 공간 | 개구·틈·안테나가 놓인 빈 공간. 내부를 PEC로 채우지 않음 |
| 정합 소자 | 우선 후처리 LC/벤더 S-parameter | 참조면, 소자 Q/SRF/실장 기생의 포함 여부 |

기하 좌표와 두께는 mm, `mesh.SetDeltaUnit(1e-3)`를 쓴다. ConductingSheet의 `thickness`는 **m**, conductivity/kappa는 S/m다. 손실 변환은 `kappa = 2*pi*f_loss_ref*EPS0*epsilon_r*tan_delta`이며 `f_loss_ref`를 여기 폭 `fc`와 구별한다. 상수 kappa는 기준 주파수에서 tanδ와 일치한다.

```python
# CSX, mesh가 만들어져 있고, 모든 기하 좌표가 mm인 경우
via = CSX.AddMetal('via')
via.AddCylinder([x, y, z_bot], [x, y, z_top], radius=drill/2, priority=200)
cu = CSX.AddMetal('cu')
cu.AddBox([x0, y0, z_top], [x1, y1, z_top], priority=100)
mesh.AddLine('z', [z_bot, z_top])
# 손실이 목적이면 cu를 다음 property로 교체하고 같은 2D 형상을 부여:
# cu = CSX.AddConductingSheet('cu', conductivity=5.8e7, thickness=35e-6)
```

## 3. 비아 — 속은 채우고, 중요한 접속에 해상도를 쓴다

**급전·IFA 단락·리턴 전환·공진기·슬롯 옆 비아**는 처음부터 실제 위치와 직경을 보존한다. x/y 중심선을 두고, 직경을 해상할 필요가 있는 위치에는 `x±r`, `y±r`의 표면 라인 또는 이에 상응하는 국부 해상도를 둔다. 공식 FAQ의 기본 메시 권고는 중심+표면이다. 도금 두께까지 잘게 나누는 뜻이 아니다. [1]

**넓고 연속적인 GND 내부의 반복 스티칭 비아**는 실제 solid 원통과 좌표를 먼저 유지한다. 기존 메시가 중심을 이미 지나면 라인을 공유한다. 많은 비아의 표면 라인을 기계적으로 모두 추가해 불필요한 근접 라인을 만들지 않는다. 중심만으로 표현된 비아는 **접속 위주 거친 근사**로 표시하며, 직경/인덕턴스 정확도가 검증됐다고 쓰지 않는다. 비아 위치를 메시별로 옮기는 방식은 사용하지 않는다.

표면 라인과 다른 필수 좌표가 매우 가까우면 먼저 중복·불필요한 보조선을 제거한다. 중요한 비아의 실제 직경/인접 갭을 바꿔 문제를 숨기지 않는다. 거친 스티칭 표현의 영향이 의심되면 이미 예정된 두 번째 실행에서 그 그룹의 해상도를 함께 보강한다. 형상 좌표·반경·비아 개수는 고정한다. 세 번째 이후 비아 메시 실험을 계속하지 않는다.

**다음은 기본값이 아니라 비용 절감용 선택 근사다.** 꼭 필요한 한 그룹만 적용하고 `approximations.json`에 남긴다.

| 선택 근사 | 검토할 조건 | 하지 말아야 할 확대 해석 |
|---|---|---|
| 먼 내부 스티칭 일부 생략 | 양쪽 GND 연속, 슬롯/리턴 전환/급전부와 떨어짐, 중요 전류 경로 아님 | ‘6 GHz 이하이면 모두 생략 가능’ |
| via fence → PEC 벽 | 차폐 경계로 동작하는 같은-net 펜스, 충분히 작은 피치·충분한 직경, 누설이 관심값이 아님 | `pitch<λg/10` 하나만으로 등가 확정 |
| 작은 GND via 배열 → PEC 블록 | 같은 net·연결층, 중간의 신호/공간/개구를 침범하지 않음 | 신호 비아/필터/열패드 형상을 일괄 블록화 |

선택 근사로 정량 결과를 주장하려면 해당 부분을 원래 비아로 복원한 **비교 1회**가 있거나, 같은 stack-up·형상 범위의 검증 기록을 재사용해야 한다. 비교도 전체 실행 예산에 포함한다. 예산이 없으면 근사를 유지한 경향 결과로 전달한다. 간단한 국부 테스트는 참고 근거가 될 수 있으나 보드 전체 방사/결합의 검증을 대신하지 않는다. 피치뿐 아니라 직경과 간격도 fence 누설에 영향을 준다. [6]

## 4. 메시 — 좌표를 정리한 뒤 한 번에 만든다

1. **형상 확정:** 원본 CAD를 보존하고 계산용 형상·재료·net·비아 목록의 해시를 저장한다. 단순화는 이때 끝낸다. 모든 비교 실행이 같은 계산용 형상을 사용한다.
2. **필수 좌표:** 시트 법선 위치, 실제 stack-up, 포트 위치, 중요한 비아, 주요 갭/슬롯 경계를 먼저 확보한다. 임의의 0.05 mm 그리드로 실제 CAD 전체를 스냅하지 않는다.
3. **보조 좌표:** Box 엣지에는 필요할 때 thirds rule을 사용한다. 공식 Python의 `AddEdges2Grid`는 검토한 rc2에서 Point/Box만 자동 처리한다. Polygon/LinPoly·회전 형상은 별도 엣지 및 국부 해상도 처리가 필요하다. [4]
4. **중복 제거:** 수치적으로 같은 보조선은 병합한다. 보조선과 필수선이 충돌하면 보조선부터 조정한다. 필수선끼리 가까운 경우는 실제 작은 형상이므로 임의로 합치지 않는다.
5. **국부 해상도:** 먼저 급전·트레이스 폭·중요 갭·중요 비아를 충분히 표현한다. 넓은 공기/기판에 같은 작은 간격을 적용하지 않는다. 직교 격자의 한 라인은 축 전체로 이어져 셀 수를 증가시킨다는 점도 비용에 반영한다.
6. **그레이딩:** 중요한 영역에서 바깥으로 점진 확대한다. `SmoothMeshLines(..., ratio=1.4)` 뒤에도 실제 인접비를 검사한다. 기준 미달이면 문제 구간만 재구성하는 수정을 최대 1회 수행한다. 동일 호출 반복으로 해결될 것이라 가정하지 않는다.
7. **PML/NF2FF:** 구조물 밖 공기 여유를 확보하고 그 바깥에 PML 8셀을 둔다. 최종 mesh/boundary 후 NF2FF를 만든다. 기록면은 필요한 구조를 둘러싸고 균질한 배경 매질에 있어야 한다.

Anti-pad/슬롯은 먼저 구멍을 제외한 시트 형상으로 만든다. 검증한 PEC 모델에서는 높은 priority의 공기 primitive로 개구를 만드는 방식도 쓸 수 있다. 다른 property·버전까지 동일하다고 가정하지 말고, 한 번 확인한 방법을 재사용한다. 원형 개구를 사각형으로 바꾸는 경우에는 선택 근사로 기록한다.

| 항목 | 빠른 검토 기본값 | 해석 |
|---|---|---|
| 공기/기판 최대 셀 | 각 매질의 `λ(f_max)/20`에서 시작 | 작은 중요 형상의 해상도는 따로 지정 |
| 기판 z 분할 | 중요한 유전체 두께당 4셀에서 시작 | 두 번째 실행에서는 필요하면 6셀 등으로 증가 |
| 트레이스/중요 갭 | 폭 방향 대략 3셀 이상에서 시작 | 얇은 PEC 비아 중심선 표현과 별개 |
| 인접 간격 비 | 목표 ≤1.5 | 1.5–2.0은 위치를 기록한 경고; >2.0은 빠른 모드 재구성 대상 |
| 최소 셀 | 0.05 mm 이상이면 관리하기 쉬움 | 0.02–0.05 mm는 비용 경고, 물리적 오답 판정 아님 |
| <0.02 mm 셀 | 기본 빠른 모드에서 본 실행 보류 | 필수 형상이면 결과 범위를 제한하거나 해법 변경. CAD를 지우지 않음 |
| 계산 규모 | 대략 5M 격자점 이하 목표 | 보장 처리량/정확도 기준 아님. setup 및 시험 실행으로 실제 비용 확인 |
| 경계 | `PML_8` ×6, 구조→PML 안쪽면 ≥λ(f_low)/4에서 시작 | MUR도 진단에 사용 가능. 경계 민감도는 증상이 있을 때 확인 |

1.5–2.0 허용은 본 문서의 **빠른 검토 운영상 예외**이며 공식 권고 1.5를 충족한 것으로 표시하지 않는다. 여기/미세 갭 부근에 큰 변화가 몰리면 거기를 우선 수정한다. 예외가 남은 결과는 수렴 비교와 함께 판단한다. 초미세 셀을 계속 추가해 숫자 1.5만 맞추는 반복을 하지 않는다.

## 5. 본 계산 전에 싸게 실패시키기

입력 단위·시트 누락·중복 좌표·포트 단락·잘못된 귀환을 여기서 잡는다. 필수 조건이 실패하면 성능 계산을 시작하지 않는다.

- 메시 좌표는 유한하고 엄격히 증가. 필수 시트 위치가 실제 grid에 존재.
- 포트 여기 축 길이 >0. 포트가 의도한 두 도체를 연결하고 PEC에 묻히지 않음.
- 최소 셀·최대 셀·인접비·격자 크기와 최악 구간 좌표를 출력.
- `setup_only=True, debug_PEC=True` 실행. 반환값과 로그 확인.
- `unused`를 원인별로 분류. 중요 도체/포트가 누락되면 실패. 단순 중복 primitive는 설명을 남김.
- PEC dump의 연결·분리·개구를 확인. 파일 존재만으로 접속 검사를 통과시키지 않음.
- `FDTD.Write2XML()`로 전체 설정을 저장. 원본 코드/재료값/환경/로그도 보존.

다음은 NumPy 배열로 **격자 비용·간격만** 검사하는 작은 함수다. PEC 연결·포트·재료 검사는 별도로 한다. `ok`가 전체 전자기 모델의 합격을 뜻하지 않는다.

```python
import numpy as np

def fast_mesh_check(lines, max_grid_points=5_000_000):
    report, errors, warnings = {}, [], []
    for ax in 'xyz':
        a = np.asarray(lines[ax], dtype=float)
        if a.ndim != 1 or a.size < 3 or not np.isfinite(a).all():
            errors.append(f'{ax}: invalid coordinate array')
            continue
        d = np.diff(a)
        if np.any(d <= 0):
            errors.append(f'{ax}: coordinates must strictly increase')
            continue
        ratios = np.maximum(d[1:] / d[:-1], d[:-1] / d[1:])
        j = int(np.argmax(ratios))
        mn, rr = float(d.min()), float(ratios[j])
        report[ax] = dict(lines=int(a.size), min_mm=mn, max_mm=float(d.max()),
                          max_ratio=rr, worst_triplet_mm=a[j:j+3].tolist())
        if mn < 0.02 - 1e-10:
            errors.append(f'{ax}: below fast-mode resource floor (0.02 mm)')
        elif mn < 0.05 - 1e-10:
            warnings.append(f'{ax}: small cell, estimate runtime')
        if rr > 2.0 + 1e-9:
            errors.append(f'{ax}: ratio >2, rebuild affected interval once')
        elif rr > 1.5 + 1e-9:
            warnings.append(f'{ax}: ratio >1.5, record exception')
    if all(ax in report for ax in 'xyz'):
        n = int(report['x']['lines'] * report['y']['lines'] * report['z']['lines'])
        report['grid_points'] = n
        if n > max_grid_points:
            errors.append('grid exceeds current fast-mode budget')
    return dict(ok=not errors, mesh=report, errors=errors, warnings=warnings)
```

허용값은 작업 시작 때 정한다. 통과시키기 위해 결과를 본 뒤 임의로 바꾸지 않는다.

## 6. 실행 조건과 시간 예산

Gaussian은 양의 f0와 관심 대역을 충분히 덮는 fc를 사용하고, 대역 끝에서 입사 스펙트럼이 너무 작지 않은지 확인한다. 메시 계산의 `f_max=f0+fc`로 둔다. f0>0만으로 DC가 정확히 없어지는 것은 아니다. 2.4 GHz 예는 `f0=2.45e9, fc=1e9`, 2.4/5 GHz 예는 `f0=4.2e9, fc=2.2e9`다. 6 GHz 대역을 검토하면 실제 관심 구간을 명시하고 별도로 설정한다.

`EndCriteria=1e-4`로 시작하고 첫 물리 시간 상한은 예를 들어 30 ns로 둔다. setup이 보고한 **실제 Δt**에서 필요한 NrTS를 계산한다. 30 ns는 완료 보장값이 아니다. 더 촘촘한 메시에서 같은 NrTS를 그대로 사용해 관측 시간이 짧아지게 하지 않는다. CFL 손계산은 추정이며 기본 Rennings 방식의 실제 Δt와 구분한다. [5]

- 예산 지정이 없으면 첫 실행의 30–60초 구간에서 처리 속도를 보고, 보통 **실행당 10분, 전체 30분 정도**를 작업 예산으로 잡는다. 물리적 합격 조건이 아니다.
- 예산을 크게 넘길 것으로 예상되면 장시간 실행 전에 불필요한 초미세 셀·과도한 공기 영역·불필요한 dump부터 줄인다. 공기 영역은 필요한 경계 거리와 함께 검토한다.
- 속도 확인은 본 실행 초반에 하면 된다. 초기화 시간을 제외하고 예상 완료 시간을 계산하며, 불필요한 별도 시뮬레이션을 추가하지 않는다.
- 시간 상한에서 멈출 때는 해당 버전이 지원하는 `ABORT`/`SetAbort` 등으로 정상 종료하고 미완료로 기록한다. 통과시키기 위해 EndCriteria를 느슨하게 바꾸지 않는다.

## 7. 결과 판단 — 보통 2회로 끝낸다

**1회차: 기본 모델.** S11/튜닝이 목적이면 PEC로 시작한다. 효율/이득이 목적이면 처음부터 같은 형상의 손실 모델을 사용한다. 마지막에 재료를 바꾼 뒤 검증하지 않은 값을 최종값으로 내지 않는다.

**2회차: 같은 형상의 확인.** 중요 영역과 필요한 최대 셀을 약0.7배로 줄이고 z방향도 필요하면 보강한다. CAD 좌표, via 개수·위치·반경, 재료, 포트, 외부 물체를 고정한다. 위상 기준면과 실제 관측 시간도 맞춘다. 비교할 필요가 없는 먼 공기까지 균일하게 잘게 만들지 않는다.

다음은 빠른 설계 검토용 기본 허용차다. 요구가 더 엄격하면 시작 전에 바꾸되, 실패한 뒤 통과시키기 위해 완화하지 않는다.

| 관측량 | 두 실행의 일치 목표 |
|---|---|
| 관심 대역 안의 같은 S11 골 위치 | 변화 ≤1%. 골이 대역 끝/평탄부에 있거나 서로 바뀌면 이 기준만 사용하지 않음 |
| 관심 대역 복소 S11 | `max(abs(S11_fine - S11_base)) ≤0.03`. 선형 복소량 비교 |
| 관심 대역 최악 S11 dB | 차이 ≤0.5 dB. 깊은 null의 최소 dB만 계속 맞추지 않음 |
| −10 dB 대역폭이 판단에 필요한 경우 | 연속 구간 수가 같고 각 경계 변화가 대역 중심의1% 이내. 문턱 근처는 판정 보류 가능 |
| 효율/이득이 필요한 경우 | 방사효율 차이 ≤3%p, 목적한 이득 차이 ≤0.5 dB를 시작 목표로 사용 |

종료 로그, 여기 종료 뒤 에너지 추세, port 시간 파형도 확인한다. 마지막5%의 전압 진폭/전체 최대 <1%는 보조 지표이며 단독 합격 조건이 아니다. 0/0·NaN·0 이하의 수용 전력·너무 약한 입사파 구간은 무효로 처리한다.

**3회차는 필요할 때만, 한 원인에 사용한다.** 관측 시간 연장, 특정 메시 영역 보강, PML 거리 변경, 선택 근사 복원 중 하나만 수행한다. 여러 조건을 동시에 바꿔 원인을 알 수 없게 하지 않는다. 해결되지 않으면 무제한 추가 실행으로 넘어가지 않는다.

기본 실행이 미완료/발산이면 보완 실행을 메시 비교보다 먼저 한다. 순서는 바꿀 수 있지만 총3회 예산은 유지한다. 유효하지 않은 기본 결과로 메시 일치를 판정하지 않는다. 상한에 도달하면 최선의 근거와 남은 범위를 보고하고 종료한다.

선택 근사 비교와 메시 확인을 모두 예산 안에서 할 수 없으면 미실행한 쪽을 미검증으로 보고한다. 빠른 검토 결과의 한계를 그대로 설명한다.

## 8. 느리거나 끝나지 않을 때의 분기

| 증상 | 먼저 확인할 것 | 최대1회 보완 |
|---|---|---|
| Δt만 매우 작음 | 축별 최소 간격, 중복/근접 보조선, 불필요한 얇은 층 | 보조선 정리. 필요한 실제 형상이면 빠른 모드 한계로 보고 |
| 안정적이지만 감쇠가 느림 | 고Q, DC/정전기 모드, 여기 종료 시점, 손실/방사/port 경로 | 같은 메시에서 물리 시간 연장. 단지 느리다는 이유로 재료 손실을 늘리지 않음 |
| 필드 성장/NaN | 단위·재료값·포트·PML 근접·비정상 격자 | 확인한 원인만 수정. 세분화나 수동 Δt 조절을 무작정 반복하지 않음 |
| 곡선은 매끄럽지만 거친/미세 메시 응답이 다름 | 급격한 셀 비, 작은 gap, via, z층 해상도, 형상hash 일치 | 지배적인 영역을1회 보강 |
| 형상 단순화에 응답이 민감함 | 생략한via/케이스/return/케이블 | 중요한 원래 형상을 복원하고 남은 한계를 보고 |

## 9. 후처리와 인계

- 주파수 평가는 **관심 대역별**로 한다. 여기 전 구간의 최소값 하나를 대표값으로 쓰지 않는다. S11 최소점과 `Im(Zin)=0` 공진을 구분한다.
- −10 dB 폭은 연결된 구간마다 반환한다. 떨어진 대역을 min/max로 연결하지 않는다. 기존 시간 파형으로 주파수 점을 추가할 수 있으면 FDTD 재실행을 피한다.
- `S11=uf_ref/uf_inc`, `Zin=uf_tot/if_tot`. 실수50 Ω 기준에서 `Pacc=0.5*Re(U*conj(I))`, `ηrad=Prad/Pacc`, `ηtotal=Prad/Pinc`다.
- 패턴 절단면2개는 절단면으로 표시한다. 전 방향 Dmax가 필요하면 전구면 각도 탐색을 한다. 각도 해상도 보강은 가능하면 같은 기록의 NF2FF 후처리만 다시 한다. `G=D*ηrad`와 `Grealized=D*ηtotal`을 구분한다.
- 근사와 미검증 항목을 명시한다. 재료 미확정·PEC via·마스크 생략을 포함한 결과는 해당 모델의 예측이며 실측값이 아니다.
- 조건별 결과 폴더에 CAD/모델hash, 메시, 재료, port, 실행 조건/종료 이유, raw 파형, 로그, 비교JSON을 보존한다.
- 모델/메시 생성 코드는 실제 형상에 맞춰 작성한다. 이 문서의 작은 코드 조각을 모든 PCB에 대응하는 검증 완료 solver 템플릿으로 취급하지 않는다.

```text
[목적과 결과] 관심 대역, S11/Zin/대역폭, 필요할 때만 효율/이득
[모델] solid PEC via / 2D copper / 재료 / 외부 구조 / 생략·선택 근사
[실행] 규모, 최소 셀, 최대 인접비, 실제Δt, 물리 시간, 실행 소요 시간, 종료 이유
[확인] 형상 고정, 시간 감쇠, 두 메시 차이, 근사 복원 비교 여부
[판정] 예비 경향 / 채택 모델 내 지정한 일치 확인 / 미완료·비교 불일치
[한계와 다음] 결론을 가장 크게 좌우하는 미확인 항목 하나와 확인 방법
```
