# openEMS 규칙 진입점

이 문서는 루트 [AGENTS.md](../../AGENTS.md)의 openEMS 조건을 만족했을 때만 읽는다.

## 언제 사용하는가

- openEMS/CSXCAD 모델·Python 스크립트를 작성·수정·실행·검토할 때
- 해당 모델의 메시·포트·경계·수렴·실행 시간 문제를 분석할 때
- openEMS 결과를 후처리하거나 그 타당성을 판단할 때

openEMS를 사용하지 않는 일반 RF/PCB 설계·KiCad·실측 교정·다른 solver 작업에는 적용하지 않는다. 규칙 자체를 검토·수정해 달라는 요청은 해당 파일을 읽어도 된다.

## 적용할 문서

**Python API로 2.4–6 GHz PCB 안테나·수동 RF 구조를 빠르게 검토하는 작업**이면 [pcb-antenna.md](pcb-antenna.md)를 읽고 적용한다. solid PEC 비아·2D 동박, 중요 형상 보존, 사전 검사, 제한된 실행 예산, 결과의 한계를 함께 다룬다.

그 밖의 대역·구조·API에서는 상세 문서를 자동 로딩하지 않는다. 해당 프로젝트의 모델·재료·정확도·검증 기준을 먼저 따른다. 특히 수백 MHz 이하의 자성 코어 전류 프로브 교정에는 이 문서의 셀 크기·시간·오차 예산을 그대로 옮기지 않는다. 사용자가 범위를 벗어난 작업에 이 규칙을 참고하라고 명시하면 필요한 부분을 읽되, 수치 기본값은 재검토한다.

## 버전과 유지관리

- `pcb-antenna.md`는 2026-09-23 검토한 `openems_agent_revised.md`를 내용 변경 없이 편입한 문서다.
- 검토 기준은 openEMS v0.37.0-rc2 / CSXCAD v0.7.0-rc2다. 다른 버전에서 관련 API가 다르면 실제 설치 버전을 확인한다.
- 상세 문서 안의 실행 횟수·메시·허용차는 빠른 검토용 운영 기본값이다. 프로젝트의 명시적 요구가 우선하며 정확도 보증값이 아니다.
- 참고자료 링크는 상세 문서 끝에 있다. 모델의 실측 정확도나 전 대역 수렴이 이미 확인됐다는 뜻은 아니다.
- 이 폴더는 일반 Markdown으로 유지한다. 본문을 루트 `AGENTS.md`에 합치거나 모든 작업에 자동 주입하지 않는다.
